案例结论

本地复现结果
在 Node 22.2.0 上原样执行报告中的 ESM 文件。三个普通进程和三个显式开启原生异步栈的进程均只报告 DNS 的 ENOTFOUND，缺少调用 read 的第 10 行。
CoroPerf 证据说明
定向采集把同一个 Error 的套接字发出事件连到 read Promise 的拒绝，再按该 Promise 的实例编号找到第 10 行。三次均吻合。按报告中的建议在 await 处包裹 AggregateError，三次原生日志也都出现该行；环回成功读取的三个进程正常退出。
适用范围与局限
报告平台为 Windows x64，此处使用同版 Linux x64 官方构建与本机系统解析器。探针包装 read 并返回原 Promise，事件关系来自该进程内的 WeakMap 对象标识。
