案例结论

本地复现结果
按发帖日期取 Trio 的当时源码和 Python 3.6.2。公开单任务示例在三次原始运行中均保留了 Cancelled 的隐式上下文。两条真实本地 socket 读取共用同一函数时，父 nursery 超时的异常由 fail_at 抛出。
CoroPerf 证据说明
单任务的默认 Python 异常格式本身就能显示阻塞位置。父作用域超时时，标准库的格式化只展示父作用域，Trio 自带的异常打印能展示子任务的共同读取行。两个任务共用这行代码，打印结果无法区分创建入口。按 Task 与协程对象把套接字读取、实际收到的 Cancelled 和创建栈相连，交换不回复的一侧后，6 次父作用域采集均指向对应的 start_profile 或 start_catalog。两边均回包时没有取消。
适用范围与局限
原帖是诊断功能讨论，未附多任务应用。双 socket 与 nursery 场景是本地受控扩展。历史提交依发帖时间选择。采集使用该版本公开的 Trio Instrument 回调和 Python 异常跟踪。原始栈由 coroPerf CLI 分析。
