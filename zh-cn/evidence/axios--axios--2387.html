案例结论

本地复现结果
同一本地账单路由返回 HTTP 500。两个 await 调用的原生错误都逐帧匹配首帖的七个函数及行列号，两个应用调用者均缺失。
CoroPerf 证据说明
图在 axios.get 返回时保留各自的应用栈。通过同一返回 Promise、同一 Error 和同一 ClientRequest，对应到外层拒绝及服务端回执，缺失的两个调用者均可区分。
适用范围与局限
首帖未提供包或 Node 锁文件。0.19.0 是发帖前发布包中唯一匹配三个 Axios 行号的版本，12.6.0 也匹配四个 Node 内部帧。使用本地普通 GET。对象关系由小型探针采集，旧 Node 的 unhandled-rejection 样本本身未识别 Promise ID。
