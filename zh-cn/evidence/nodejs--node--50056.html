拼接补回了什么

两个调用者在 await 后的热点调用栈相同。CoroPerf 先确定当时活跃的 Promise 实例，再拼回其创建栈，把同一个被调用者分别连到 launchProfile 和 launchInventory。

栈帧保留在各自的采集块中。拼接点表示两个采集块之间有可核实的关系。拼接栈里的实例标签取自该实例在本次采集中首次出现的记录号。

案例结论

本地复现结果
Node 24.18.0 的三次普通 CPU 采样共有 603 个观测落在 sharedService 和 busySpin 中，均看不到两个应用发起者。每次运行都覆盖两个调用者。
CoroPerf 证据说明
CoroPerf 使用 async_hooks 记录的进入和离开区间，将 579 个 CPU 观测归到当时活跃的运行时实例，再拼接其创建栈，恢复 launchProfile 或 launchInventory。独立记录的请求标签和执行时间全部吻合，包括反转执行顺序的对照。
适用范围与局限
这是缺失异步调用来源的双入口改编实验，在 Linux 使用 V8 CPU profiler。原帖使用的 fast-blocked-at watchdog 和 Node 20.5.1 环境不在本次复现范围内。采样数量衡量归属正确性。
