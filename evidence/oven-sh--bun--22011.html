Issue findings

Local observation
Bun 1.2.20 passed its own syntax-error test on PostgreSQL 14. A valid query returned 1, while the invalid query returned SQLSTATE 42601 with an undefined stack.
What CoroPerf showed
A separate Promise catch exposed its callback stack, and the earlier graph showed onRejectPostgresQuery. Version 1.4.4 supplied a one-line message but failed the old test’s SyntaxError type assertion.
Scope and limits
The reporter’s query, schema and application code were unavailable. The test’s error location differed from the reported VALUES position.
