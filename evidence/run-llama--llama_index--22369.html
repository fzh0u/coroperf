Issue findings

Local observation
In the posted script the background wait fell from 111 ms to 11 ms with the proposal, and the two-query Qdrant run fell from 416 ms to about 260 ms with identical results.
What CoroPerf showed
Each router task read its HTTP response synchronously, delaying an already-created downstream task. The proposal let both queries wait concurrently on async sockets.
Scope and limits
Local fixed embeddings and real vector retrieval, with 200 ms of controlled relay delay per response. The proposal was unmerged.
