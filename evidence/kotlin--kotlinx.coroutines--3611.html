Issue findings

Local observation
The D8 debug build showed worker.await() at line 27, while the optimized build retained only the I/O-side throw and scheduling frames.
What CoroPerf showed
With debugging on, line 27 returned only when both the forced-false getter rules were removed and continuation metadata and label fields were preserved.
Scope and limits
This feature request supplied no production APK or rules. The local Android test establishes the behavior of that configuration.
