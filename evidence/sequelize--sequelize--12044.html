Issue findings

Local observation
In the reporter’s duplicate-username example, create showed only Query.formatError, Query.run and microtasks, while findOrCreate retained model.save, findOrCreate and the test line.
What CoroPerf showed
The second create’s task linked the application call at line 9 to the catch at line 11. Plain INSERT formatted the driver error there, while findOrCreate returned it through a SQL wrapper.
Scope and limits
This covers the public PostgreSQL example with a minimal local model. The opening post’s length-validation model was unavailable.
