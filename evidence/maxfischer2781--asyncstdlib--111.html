Issue findings

Local observation
The example yielded uvw, abc, xyz, def, while the stable standard-library merge yielded abc, uvw, def, xyz.
What CoroPerf showed
Distinct heap wrappers inherited identity-based equality, so equal keys never reached the tuple’s source-order tiebreaker. Changing only equality produced the expected order and matched the observed comparisons.
Scope and limits
The report did not pin versions. Python probes captured the comparisons around the C tuple operation, and Task attribution covers the merge’s main Task.
