Issue findings

Local observation
The reporter summed three items, 1, 2 and 3, with initial=None. Both 3.13.1 and the immediate parent of PR #178 returned [None, 1, 3, 6]. The merged fix and 3.13.2 returned [1, 3, 6], matching itertools in the same program. All four calls completed successfully.
What CoroPerf showed
On the affected build the first yield occurred before the input generator supplied 1. The reducer then received (None, 1). The fixed build read 1 before its first yield and first called the reducer with (1, 2). The captured caller created the reporter’s collector coroutine at line 32. That identical object returned the measured list at line 30.
Scope and limits
Each build ran in two plain and two instrumented processes on a local asyncio event loop. Coroutine identity covers the reporter’s collector. The library’s async generator has physical yield samples. This experiment uses finite streams in one process.
