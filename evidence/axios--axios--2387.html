Issue findings

Local observation
Two awaited GETs to the same local billing route returned HTTP 500, and both errors matched the report’s seven frames while omitting both application callers.
What CoroPerf showed
The creation stacks at axios.get, matched through Promise, Error, and ClientRequest identities to the server receipts, distinguished the two callers.
Scope and limits
Axios 0.19.0 and Node 12.6.0 were inferred from frame locations. A separate probe established object identity.
