Issue findings

Local observation
With the reporter’s two blocks and ten integers, Ray 2.43.0 counted ten source rows but zero MapBatches output rows. Version 2.45.0 returned all inputs and powers in order.
What CoroPerf showed
Each block queued its end marker before its batch Task queued the rows, so the consumer saw only two markers. Waiting for the tasks before sending the markers, or disabling order preservation, restored all ten rows.
Scope and limits
One local CPU cluster, one map actor and one row per batch. The reporter’s development commit was unspecified.
