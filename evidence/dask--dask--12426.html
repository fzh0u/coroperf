Issue findings

Local observation
Dask 2026.3.0 failed all 55 of the reporter’s Series tests. Mapping destinations to states for 2,000 flight records exposed a second symptom. The airport directory contained every destination, yet 1,804 results were missing. Dask 2026.6.0 passed all 55 tests and returned every state.
What CoroPerf showed
The failing test reaches Map._divisions with the expected pandas Series in the slot for a Boolean flag. In the flight run, the old scheduler plan split the airport directory by row index. The pandas.Series.map call for one Albuquerque flight had 81 airport keys and lacked LAS. After the fix, each worker call saw all 3,376 keys and returned the state for every destination.
Scope and limits
The replay used Dask’s local threaded scheduler. SQLite and a separate Python dictionary agreed on every reference value. Removing LAX erased exactly the 94 flights to that airport on the fixed build. The separate Index tests still had 25 failures on that build. The recorded frames cover synchronous worker calls.
