Issue findings

Local observation
The original con.commit() succeeded, but cur.connection.commit() raised a cross-thread SQLite ProgrammingError on both 0.20.0 and 0.22.1. Both commits succeeded with the proposed change.
What CoroPerf showed
The cursor property returned the raw handle, so the Task committed on the event-loop thread. Returning the async wrapper sent the same handle’s second commit back to its owning worker thread.
Scope and limits
Used the reported interpreter and package versions. PR #384 was tested separately as a proposal, and worker operations were matched by handle identity.
