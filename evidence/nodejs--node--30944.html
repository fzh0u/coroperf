Issue findings

Local observation
Callback and Promise reads of a missing file both returned ENOENT without the initiating JavaScript frame, while the synchronous read showed its origin.
What CoroPerf showed
GDB observed native error construction with execution ID zero, and libuv request addresses and V8 objects linked subsequent delivery to the actual requests.
Scope and limits
The reported Node version ran on Linux. No active JavaScript parent was observed at native error creation.
