Issue findings

Local observation
All ten inputs were yielded, but the 100 ms heartbeat paused for seconds; using the posted async iterator or running next in an executor restored the heartbeat.
What CoroPerf showed
An independent thread stack caught the consuming task in time.sleep while from_iterable advanced the generator, and the executor control placed that same line on a worker thread.
Scope and limits
Upstream described synchronous iteration semantics and proposed no fix. The named task origin came from a separate two-input control.
