Issue findings

Local observation
Requests to the URL generated for /hello world/{name} returned 404, as did requests under a static directory prefix containing a space.
What CoroPerf showed
Ordinary paths and an alternative route to the same file worked, and the recorded lookup keys narrowed the discrepancy to how registration and request resolution encode the path.
Scope and limits
One named route and one directory were tested with ordinary spaces. The upstream PR was still open.
