Issue findings

Local observation
In three runs on 2.1.5, reading the frozen Core result raised TypeError, while freezing an ORM result raised AttributeError. The fix replayed both Core rows and froze the ORM result.
What CoroPerf showed
FrozenResult saved the async fetchall return object directly, and its creation, cache read and unawaited warning matched by identity. The ORM path requested a missing _raw_row_iterator.
Scope and limits
Tested on real SQLite. The fetchall coroutine never executed. Task creation and execution were verified for the cache writer and reader.
