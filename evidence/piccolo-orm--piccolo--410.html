Issue findings

Local observation
Both == None and is_null() generated IS NULL$1 on 0.66.0 and the fix parent, and PostgreSQL returned 42601. The fix commit and 0.68.0 returned only the expected row, id=1.
What CoroPerf showed
The old query builder serialized an UNDEFINED object, and the resulting SQL and argument matched what the driver received. The fix omitted the argument and returned the same row as psql.
Scope and limits
The report supplied the two expressions. The local schema and four rows were reconstructed, and Task attribution covers query execution only.
