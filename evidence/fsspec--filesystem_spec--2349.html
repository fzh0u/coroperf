Issue findings

Local observation
The reporter’s script read all lines successfully. After reopening the same HTTP resource, readline() raised ValueError. That call received 14,999 bytes from the background read and consumed 15 bytes for its first line.
What CoroPerf showed
The submitting thread and the event-loop task shared the same coroutine object. The bytes returned by _read matched the buffer passed to the rewind request. The fix retained the remaining 14,984 bytes so the next line could use them. Both HTTP backends then returned all 2,000 flight records in order.
Scope and limits
The coroutine evidence covers the aiohttp background read. The rewind exception occurred on the synchronous caller. The Requests backend provided a separate output check. All requests used a local HTTP server.
