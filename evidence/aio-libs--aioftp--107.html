Issue findings

Local observation
A local FTP server listed three files, including a readable February 29 file. aioftp 0.15.0 and the fix parent exited successfully but returned only the February 28 and March 1 entries.
What CoroPerf showed
The listing task received the February 29 line and hit ValueError in both date-parsing paths. The iterator skipped the entry. The fix parsed the same timestamp as 20200229092400.
Scope and limits
The original server and Python patch release were unspecified. The test used a read-only loopback FTP server and an English UNIX listing with the client clock set to March 1, 2020. The traced task was the top-level task in the posted client.
