Issue findings

Local observation
In both runs, only one of ten concurrent requests received a reply within 500 ms when the subscription callback took 300 ms per message.
What CoroPerf showed
Deferring WaitGroup.Done removed the test’s separate one-second timeout but left nine request timeouts, while a second subscription on the same subject and connection received all ten messages in order despite the slow callback.
Scope and limits
The loopback test used a contemporary release because none was specified. Scheduling determined which request succeeded.
