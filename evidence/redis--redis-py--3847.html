Issue findings

Local observation
After release was cancelled, Redis still held the lock although the original client considered its ownership lost.
What CoroPerf showed
The client cleared the token before the actual release. Comparing lock state and retry outcomes on the affected and fixed versions distinguished the two steps.
Scope and limits
The replay used the upstream function snippet and a private Redis instance.
