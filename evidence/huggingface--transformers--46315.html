Issue findings

Local observation
In the author’s Chinese BERT example, 100 conversions of 360 tokens with 5,005 added tokens took 87.045 seconds on 5.9.0 and 0.018 seconds on 5.12.1.
What CoroPerf showed
Traces showed the membership check and the subsequent lookup both rebuilding the map; removing 5,000 extra entries while preserving the output also sharply reduced conversion time.
Scope and limits
The local run used Python 3.12.4 rather than the reported 3.12.13. Detailed request traces used six tokens each and cover token conversion only.
