Issue findings

Local observation
With 20 streams of 2,048 chunks, stock and fixed builds both reconstructed all text. Throughput was 1,993 versus 1,753 tokens/s, while concurrent /tokenize p95 fell from 155 to 57 ms.
What CoroPerf showed
Both stock request Tasks ran incremental detokenization on the loop despite four renderer workers, while the paired fix submitted that work to an executor.
Scope and limits
Each build had one unprobed GPU-less run with a local tokenizer. HTTP timings include client and logging costs and do not establish production inference throughput.
