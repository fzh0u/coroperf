Issue findings

Local observation
Treelite 0.93 changed six of ten scores in the maintainer’s LambdaRank regression, including a score of 2.0 that became −1.095265. Those six changes produced zero strict pair inversions in that fixture. On an additional workload with signed feature hashing, 658 of 768 held-out scores changed, reversing 1,181 candidate pairs across all 50 queries. For 19 queries, the returned and reference top sets had no common candidate. The original LightGBM example features passed on all four builds.
What CoroPerf showed
GDB stopped in the generated predictor at the split on feature 25416. The sparse row omitted the feature. Treelite 0.93 entered leaf 0 and the running score became −1.095265. The fix continued to leaf 5 and produced 2.0, matching native LightGBM and the dense control. An independent walk of the archived trees counted 2,339 changed leaves across the hashed sparse queries in 0.93. The source parent produced 1,180 strict inversions and the fixed builds produced zero.
Scope and limits
The reporter’s trained model and validation matrix were unavailable. The public ranking comparison uses LightGBM’s distributed train/test split and a separate signed-hash transformation. Strict inversions exclude near ties within 1e−6 on either ranking. A separate dense observation concerns only the source parent. In row 702 both physical predictors read present feature 64 as 0.49999999999999994 and its low word as −1. The parent reached a leaf worth -0.0925675473, and the fix reached one worth -0.0028503143. That single dense score change produced zero strict inversions. The captured execution is synchronous.
