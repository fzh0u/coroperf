Issue findings

Local observation
In each request order, three of six batched requests returned the wrong model while ordinary calls stayed correct. The fixed version answered all 12 batched requests correctly.
What CoroPerf showed
Reversing the first request reversed the wrong answer. The fix carried each model ID into the queue and split the batch so each processing task read its own ID.
Scope and limits
The reported deployments used strings as model objects. Graphs cover the model replica. Sequential request logs link it to clients and other actors.
