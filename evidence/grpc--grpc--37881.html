Issue findings

Local observation
At the reported gRPC Python revision, synchronous SayHello read and returned None for the request ID, while the async handler returned the expected ID.
What CoroPerf showed
The interceptor task retained the ID through run_in_executor, but the worker thread read the default; copying the context at submission preserved the ID across the same thread switch.
Scope and limits
The missing greeting.proto was reconstructed. The context-copy patch was tested locally and its PR closed without merging.
