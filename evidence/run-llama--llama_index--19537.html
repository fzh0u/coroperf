Issue findings

Local observation
The five expected first coordinates [1,10,3,20,30] came back as [10,20,30,1,3], and all five retrieval queries against a reloaded CPU index chose the wrong document before the fix and the right one afterward.
What CoroPerf showed
The cache held the correct vectors, but batching grouped them by hit status while binding used input order. 78 of 99 configurations mismatched before the fix and none did in either fixed control.
Scope and limits
The reporter used fixed mock embeddings. Retrieval impact was measured separately with a real, persisted TF-IDF index.
