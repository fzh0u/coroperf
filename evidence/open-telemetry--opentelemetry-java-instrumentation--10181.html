Issue findings

Local observation
The original Spring/JPA, MySQL and OpenTelemetry application stalled on the affected JDK and returned HTTP 200 on the fixed JDK.
What CoroPerf showed
A core dump linked the MySQL read to the virtual thread’s onPinned path and a native thread in transition, while uninstrumented HTTP requests independently confirmed the stall.
Scope and limits
Identifying the VM transition required a HotSpot core dump and Serviceability Agent inspection.
