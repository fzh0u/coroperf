Issue findings

Local observation
The input contained 2,845,342 accidents. Dask 2023.4.1 kept that total but reported 78,677 severity-2 accidents for 2021. A row-by-row count found 1,487,713. The fixed version returned the independent counts for every year and severity. A single-partition read also returned the correct counts on the parent.
What CoroPerf showed
In one captured _value_counts_aggregate call, a severity-2 subtotal of 324,582 was labeled 2020 before Dask reassigned the MultiIndex levels and 2018 afterward. The integer codes and counts stayed identical across that line. The parent copied the year labels from the input in a different order. The fixed build kept the result labels in their original order across all six recorded aggregation calls.
Scope and limits
The report linked to a dataset with multiple releases. The archived December 2021 CSV differs from the reporter’s copy in all 18 published reference cells. The table separates the two sets of counts. The maintainer’s pandas 1.5.3 example ran with its local file path replaced. The stock runs used the default scheduler. The two stack captures used the synchronous scheduler and reproduced the same totals and groups.
