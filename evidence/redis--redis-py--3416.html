Issue findings

Local observation
In two 200,000-command transactions, no heartbeat ran during 589 ms and 624 ms of packing, although all replies and all 17 final counter values were correct.
What CoroPerf showed
Packing ran in the caller’s Task and the pause followed the larger batch. The fix moved packing to a thread, while later changes yielded 199 times in each of two reply-processing loops.
Scope and limits
Tests used local Redis 6.0.16, RESP2 and the Python parser. The reporter supplied the batch size and source but no complete workload.
