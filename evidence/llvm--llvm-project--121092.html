Issue findings

Local observation
Clang 18.1.8 emitted four __coro_frame variables and one frame type at -O0, but the variable was absent from both IR and ELF at -O1, -O2 and -O3.
What CoroPerf showed
At -O2 the promise had only dbg.assign and both declaration lookups failed. Disabling assignment tracking yielded a dbg.declare match and restored the ELF frame type, with identical machine code at each paired optimization level.
Scope and limits
The closing patch addressed debugger access inside a resume function. Its parent already emitted the type, unlike Clang 18.
