Issue findings

Local observation
Reading the array first returned strings, the next scalar came back as the plain string paper, and querying row 2 with Choice.paper raised DataError.
What CoroPerf showed
The array codec was built with CODEC_C/BINARY in the affected release and CODEC_PY/TEXT after the fix, pinpointing the format selection during codec construction.
Scope and limits
The local PostgreSQL 10.23 baseline used Python 3.7.6. The GDB and asyncio evidence came from separate processes.
