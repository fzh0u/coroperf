Issue findings

Local observation
River 0.25.0 and the immediate parent returned a predictive standard deviation of 0.44723478. Computing the posterior independently from the 5,000 actual training rows gave 0.20001895. The landed source and 0.26.0 returned that value. The point prediction was 1.69998705 across all four builds.
What CoroPerf showed
Segment 1 records the variance computed by the regressor and the value it passed to the Gaussian constructor. On the parent, it passed the square root of that variance. Segments 2 and 3 identify the variance state attached to the returned Gaussian. Segment 4 records the caller reading sigma on that same object and taking a second square root. On the landed source the constructor received the variance itself. A zero-valued feature produced the expected sigmas 1, 0.5, 0.2 and 0.1 at noise precisions 1, 4, 25 and 100 on both corrected builds. Only the first precision concealed the defect on the affected builds.
Scope and limits
The report used Windows and CPython 3.13.14. These measurements used Linux and CPython 3.12.8. The posted program completed on both source commits and 0.26.0. On 0.25.0 it trained the same model but stopped at the private field _idx. The release result comes from its public prediction on that trained instance and the original query. The landed regression uses an untrained empty query, which 0.25.0 rejected before reaching the assertion. Each profiled call ran synchronously and the graph has zero coroutine origins.
