Issue findings

Local observation
With the author’s Serve app and an empty OS page cache, the first requests took 54.4 and 56.7 ms, and Serve logged 8.0 and 7.8 ms for loading versus 9,543.2 ms in the report.
What CoroPerf showed
The replica task read the file through predict → load_model → get_model, reusing it for the same model ID and evicting it for a new ID; prewarming the file or visiting Swagger first did not reproduce the delay.
Scope and limits
The public attachment reads ONNX bytes on local Linux storage. Docker Desktop shared-mount performance and the private MLflow model remain unknown.
