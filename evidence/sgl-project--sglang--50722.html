Issue findings

Local observation
In the independent HTTP streaming test, baseline throughput medians are 49,336 chunks/s before the change, 23,507 on the affected commit, and 47,340 after the merged fix. In each of two short traced runs, all 256 affected output Tasks made seven checks for eight chunks. The repaired runs show one check per output Task.
What CoroPerf showed
cProfile shows the aggregate check count and its immediate caller. Matching the actual Task joins otherwise identical cancelled-receive samples 1977 and 1978 to output Task creations 1463 and 1208, then to separate ASGI request creations 951 and 696. Record 2881 shows the distinct disconnect listener on the same request Task that created output Task 1463.
Scope and limits
The comparison runs the pinned SGLang stream methods over real loopback TCP, Starlette and Uvicorn. A controlled source supplies stream chunks. The medians use four uninstrumented runs per variant. The original GPU model throughput is outside this replay. PR #50741 merged.
