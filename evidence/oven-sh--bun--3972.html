Issue findings

Local observation
On Bun 0.7.3 and 1.2.20, lstat on a missing path produced an error without an application stack.
What CoroPerf showed
Pausing at rejection on 1.2.20 showed native lstat, its Promise wrapper and the awaiting main. Version 1.4.4 showed the application line, and creating the directory made 1.2.20 succeed.
Scope and limits
Used a local test path, with separate working directories for the existence control and the Inspector run.
