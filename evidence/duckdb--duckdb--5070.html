Issue findings

Local observation
For two rows with the same group and value 7, DuckDB 0.5.1 twice counted zero instead of one. Reversing the rows produced one.
What CoroPerf showed
Deduplication claimed the key before testing the type filter, so the first ineligible row excluded the later eligible row. The fix counted one in either order.
Scope and limits
The original used Windows. The Linux CLI replay used GDB to inspect row indices and return values on this small query.
