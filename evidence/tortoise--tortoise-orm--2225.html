Issue findings

Local observation
The database contained row 101 referencing the UUID, but 1.1.7 and the fix’s parent returned an empty list, while the fix and 1.1.9 returned [101].
What CoroPerf showed
Both queries used app_id, but the old ORM bound the integer primary key as text and the fixed ORM bound the UUID named by to_field, as confirmed by SQLite and an independent join.
Scope and limits
SQLite and the fixture rows were supplied locally. Task creation was verified only for an additional reverse-prefetch query.
