Issue findings

Local observation
The same fitted regressor predicted 3.452764 kW for a household meter record. Its ONNX export predicted 2.885078 kW. In total, 13 of 4,032 held-out records differed from scikit-learn by more than 0.001 kW. The tensor entering the ensemble matched the original preprocessing output on every row.
What CoroPerf showed
At tree 4, node 40, the converter received a threshold of 1166882752. The ONNX node stored 1166882816, exactly equal to this record’s float32 input. That moved the record to the lower leaf. Six trees changed leaves. Changing one split at a time reproduced each tree’s predicted contribution. Editing all six together restored the output to 3.452763796 kW.
Scope and limits
The report identified the pipeline stages but supplied no training set or model. We fitted that architecture on UCI household and bike records plus a four-input boundary case. The household model uses calendar seconds as a float32 feature. Error here means a difference from the original model. The upstream 50-row regression test passed on both revisions. The measured paths run synchronously.
