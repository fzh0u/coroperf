Issue findings

Local observation
Across four repetitions, the selector-timeout stack included the user function, while evaluate after an explicit browser close produced a Target closed stack without it.
What CoroPerf showed
In both instrumented runs, the same Error object led back to the Promise returned by Page.evaluate, whose creation stack identified puppeteerTargetClosedError at line 5.
Scope and limits
Used the original script with a Linux headless launcher. The match relied on object identity, and upstream did not confirm a mechanism.
