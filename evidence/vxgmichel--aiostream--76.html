Issue findings

Local observation
Under 0.4.3 and the merge parent, awaiting either an empty stream or an exhausted one-shot iterator raised StreamEmpty with an UnboundLocalError context. The merge and 0.4.4 raised StreamEmpty directly.
What CoroPerf showed
CoroPerf links the real await-wrapper coroutine and its allocation stack to both exceptions in the same wait_stream frame. The first exception came from reading an unassigned local. The fix tracks whether the iterator yielded any item. Every build accepts None as a last item, repeats a repeatable stream and preserves NameError from a user callback.
Scope and limits
The reported application was private. The runs reproduce the library behavior with a standalone example. The local timings include the start of the prepared component process.
