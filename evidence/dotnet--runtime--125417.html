Issue findings

Local observation
After resumption, both traditional async and verified v2 methods on .NET 11.0.0 omitted OuterMethod. The PR build showed MiddleMethod → OuterMethod on all five direct v2 runs and none in physical-stack mode.
What CoroPerf showed
In the PR build, Main remained absent in all five runs through NonAsyncHelper even after the outer task suspended, while directly awaiting AsyncHelper restored it in all five.
Scope and limits
This tests draft diagnostic behavior. The public API lacks a per-frame continuation flag, and the full IL-mapping experiment was outside the replay.
