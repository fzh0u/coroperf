Issue findings

Local observation
The maintainer’s program printed only effect and run on 2.0.0, while 2.0.1 also printed POJOService.foo and something.
What CoroPerf showed
Both missing methods were still visible on entry to Cause.fail, matching PR #7016’s finding that ZIO.attempt omitted the exception’s Java stack from Cause.Fail.
Scope and limits
The same example from the upstream comment was compiled and run against both released dependencies.
