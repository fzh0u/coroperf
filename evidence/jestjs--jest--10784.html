Issue findings

Local observation
A test rejected an Error inside the VM, but strict mode ultimately reported only ERR_UNHANDLED_REJECTION, and handling the same rejection avoided a fatal process error.
What CoroPerf showed
The rejection probe retained the test’s original stack, while the host realm’s instanceof check failed and the fatal listener later saw Node’s replacement error.
Scope and limits
The result is specific to the tested Node and Jest versions. VM setup and the fatal-error listener were additional probes.
