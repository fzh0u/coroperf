Issue findings

Local observation
With seed 0, four pixels of the 5×5 mask became 0.01823359 and 16 pixels were outside the label set after inversion, while the merged fix and release 0.6.9 produced no invalid pixels.
What CoroPerf showed
The inner container retained the image key when processing the mask. Passing the actual key restored nearest-neighbor labels, independently checked from the transform matrix, and raised the CPU test count from 5/7 to 7/7.
Scope and limits
The reporter did not give a seed. Local runs fixed seeds 0 and 17 and used a CPU PyTorch build.
