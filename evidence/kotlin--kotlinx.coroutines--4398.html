Issue findings

Local observation
With assertions and debug off, the maintainer’s JVM example showed doWork at line 6 and the worker at line 15, but omitted the API await at line 18 and runBlocking at line 27.
What CoroPerf showed
The worker belonged to the API singleton’s Job while runBlocking awaited it. Adding code after await produced an API state machine, allowing debug recovery to show line 18.
Scope and limits
The reporter’s Android snippet omitted two functions, and no original APK or mapping was available. Job ownership was verified in the maintainer’s JVM example.
