Issue findings

Local observation
In the posted increasing series, the maximum is the last of three values. The affected accelerated path returned position 0 for all eight full windows. On 1,461 daily Seattle temperature records, it selected a day without the highest temperature in 1,254 of 1,455 seven-day windows. For the lowest temperature it selected a wrong day in 1,255 windows. Both counts fell to zero after the fix.
What CoroPerf showed
The recorded stack reaches DataArrayRolling._bottleneck_reduce. Its backend counts positions from the right edge of a window. The old wrapper returned that offset directly. The fixed wrapper subtracts the offset from the window width minus one. For the week ending January 7, 2012, the highest temperature was 12.8 °C on the first day. The affected wrapper pointed to the seventh day.
Scope and limits
Tests covered in-memory arrays with complete trailing windows. Ties were accepted whenever the selected day had the actual extreme temperature. Python reference calculations, a separate SQLite query, the NumPy reduction and the backend-disabled path were checked. The local interpreter was CPython 3.12.4 and the report used 3.12.0. The stack covers the Python wrapper and the return from Bottleneck 1.3.7.
