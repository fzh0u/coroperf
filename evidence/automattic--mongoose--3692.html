Issue findings

Local observation
An uninstrumented local duplicate-key write showed only driver and receive frames, matching the report’s 14 file positions in order on two historical Node versions.
What CoroPerf showed
Moving the conflict to the other write moved the error reply from request 1 to request 2. Wire IDs and callback identity traced the latter to writeFromImport at line 11.
Scope and limits
The report omitted the operation, error code and caller. Per-request attribution required local protocol and queue probes. The generic agent saw only the shared socket.
