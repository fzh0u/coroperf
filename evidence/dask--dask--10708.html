Issue findings

Local observation
In two uninstrumented runs over 2,592,000 rows in 30 partitions, all tasks succeeded and all 26 names survived, but every selected row differed from pandas’ first row for that name.
What CoroPerf showed
All 30 local candidates per name were present, but a later partition could come first. The fix retained input partition numbers and sorted by them during output conversion, also verified by patching the original workers.
Scope and limits
Fixed random seed and two local TCP workers. Three full-size instrumented runs had 0, 0 and 26 wrong rows, so the frequency is undetermined.
