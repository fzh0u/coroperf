Issue findings

Local observation
On Tortoise ORM 0.16.1, the reported Count over events__participants raised JoinException before SQLite received a SELECT. The database contained one event and two teams in the populated tournament. Raw SQL returned two for that tournament and zero for the empty one. Releases 0.16.0 and 0.16.2 returned both counts, and the direct event-participant count returned two on all three releases. Each result repeated in a second run. The report also tried to print the annotation on a list. That raised AttributeError after a successful await on the two working releases. The upstream regression reads the value from the first returned model.
What CoroPerf showed
The resolver in 0.16.1 produced events followed by participants, then reversed that list. The first attempted join referenced event before that table had been joined to tournament. The physical stack follows PyPika validation through the join builder and QuerySet.__await__ to the failing await in the upstream regression. The test runner’s creation call and the propagation of the same exception into the running test are linked by the CPython coroutine object, its frame, the current asyncio task and its root frame. The filtered QuerySet also matches from allocation through the throw. PR 328 removed the extra reversal. Its parent and merge differ in just one ORM package file.
Scope and limits
The origin edge belongs to TestAggregation.test_nested_aggregation_in_annotation, the caller that awaits the reported query. On 0.16.1 synchronous query construction failed before the ORM created its _execute coroutine. The traceback identifies Python 3.7.6. We selected PyPika 0.36.0 from the traceback source lines and used SQLite 3.31.1 for every build. The public-data controls import every game and team from the frozen 1930 and 2018 World Cup schedules. All ten saved databases matched the same 164 source memberships. Both nested counts failed before SQL on the affected release and exact parent. The exact merge returned 36 entries and 13 distinct teams for 1930, and 128 and 32 for 2018.
