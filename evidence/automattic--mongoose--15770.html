Issue findings

Local observation
Creating a document with a field below its minimum raised ValidationError without the application call site in its ordinary stack.
What CoroPerf showed
On 8.17.1, the same Promise linked createUnit’s model.create call to the failed minimum check in Document.invalidate, while a valid document was written successfully.
Scope and limits
The error came from model validation. The successful write only checked the MongoDB data path.
