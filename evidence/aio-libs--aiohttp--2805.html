Issue findings

Local observation
The report requested the last 5,678 bytes of a resource. On a 10,000-byte file, aiohttp 1.2.0 and the fix parent returned slice(None, -5678, 1). An application using that slice sent the first 4,322 bytes. The fix returned slice(-5678, None, 1) and the application sent exactly the last 5,678 bytes.
What CoroPerf showed
The range parser put the negative offset in the slice's stop field. The fix moved it to the start field and left the stop open. The built-in static handler understood the old representation and served the correct tail on all five runs. The parent and fixed captures connect each property return to the exact RequestHandler.start task created by aiohttp, its request and its TCP connection. In the affected source-parent capture, 1.220375 ms elapsed from the recorded create_task return to the http_range return for the reported request. Both timestamps come from the same process's archived monotonic clock.
Scope and limits
The reporter supplied the header, the aiohttp version and both slice values. The resource follows the fix's regression fixture. The byte-returning application, static route and additional ranges are local controls. Each measured connection carried one successful GET. The upstream regression tests ran separately with their original mocked request helper.
