Issue findings

Local observation
With two default-executor threads occupied by synchronous reads, all three uninstrumented localhost requests raised ConnectTimeout in getaddrinfo and never reached the server.
What CoroPerf showed
All three traced requests reached the resolver submission stack. Their Futures were cancelled before the resolver ran, after a median of 241 ms. All nine uninstrumented control requests returned HTTP 200 across the private-pool, one-free-worker, and idle runs.
Scope and limits
The report omitted the application and production concurrency. The local asgiref pipe reads established this mechanism on Linux CPython 3.11.
