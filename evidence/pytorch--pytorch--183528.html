Issue findings

Local observation
The reporter exported a 4×4 tensor containing 1 through 16. PyTorch eager and the opset-18 export both requested a 3×3 average with one cell of padding. On ORT 1.23.2, 1.27.0 and 1.28.0, five of the nine results were too small. The last row was [3, 5, 1.7777777910232544]. Release 1.29.0 returned [4.5, 7.5, 4] and matched the exact reference rounded to float32 at every position. All four releases passed the floor-mode, padding-exclusion and opset-19 controls.
What CoroPerf showed
The bottom-right window includes 16 and three padding zeros. In each affected shipping binary GDB read 16 and 9 from the registers at the divide instruction and caught the resulting write to that output cell. In 1.29.0 the divisor was 4 and a hardware watchpoint recorded writes of 0, 16 and 4. The source fix directs this configuration to a loop that stops counting at the edge of the explicit padding. Real-data measurements ran the same exported ceil and floor models on 7,188 unscaled quadrants from all 1,797 UCI test images. Each affected release returned exactly 21,293 incorrect ceil outputs on 6,957 tiles across all images. Dividing by nine accounted for every discrepancy. All 64,692 ceil values were correct on 1.29.0 and all 28,752 floor values were correct on every release. Both independent batches produced identical float32 bytes. E. Alpaydin and C. Kaynak, Optical Recognition of Handwritten Digits (1998), UCI Machine Learning Repository, CC BY 4.0.
Scope and limits
These measurements cover pooling layer values on the CPU. The digit labels identify groups of images. The report used a CUDA-capable PyTorch debug build and Python 3.10. This CPU replay uses PyTorch 2.11.0+cpu and Python 3.11. The parent and fix commits were inspected as source. All recorded arithmetic and full native stacks come from the released x86-64 wheels. The debugger used a bound output buffer to observe the store. Ordinary session.run calls separately verified every returned value. The physical graph contains synchronous samples and has zero coroutine origins.
