Issue findings

Local observation
In a three-controller KRaft cluster, a five-second idle-write interval drove the active controller’s EventQueueTimeMs p99 to 5,000 ms in both affected runs, versus 0 ms in both patched runs and both 3.3.0 runs.
What CoroPerf showed
Changing only QuorumController removed the timing call for the scheduled write while replication continued and ordinary createTopics requests still updated the metric.
Scope and limits
The test covers the idle-controller false positive. Production backlog, failover, and other delayed events were outside its scope.
