Issue findings

Local observation
Cassandra 3.0.9 sent the same one-column reply for an existing partition with a null s2 and for an absent partition. The fix included the integer column s2 with a null value for the existing partition. Six three-node clusters produced 60 conditional results and 216 table readbacks.
What CoroPerf showed
Coordinator stacks identify the read filter, the failed predicate and the result builder. The parent read zero rows from the existing partition. The fix read one clustering row, giving the result builder enough information to include s2. Both versions returned its value 7 in the non-null control and reported success when the condition matched.
Scope and limits
The report compared Cassandra 2.x and 3.x. Local runs covered stock 3.0.9 and 3.0.10 and the exact changed production class on 3.0.9. One- and three-replica controls checked data and Paxos ballots. The captured JVM stacks identify worker threads.
