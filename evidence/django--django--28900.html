Issue findings

Local observation
On two independent PostgreSQL clusters, the upstream test returned [1, 1, 2, 2, 3, 4, 4] on the fix parent and [False, True] after the fix.
What CoroPerf showed
Selecting only the outer annotation left values_select empty, so UNION deduplicated full five-column rows. The fix passed is_creator to both branches, and projecting it inside each old branch also returned the two booleans.
Scope and limits
Synchronous PostgreSQL regression test with the original OuterRef(pk). No async Task identity was recorded.
