Issue findings

Local observation
A callback-based pool.query returned MySQL error 1054 with only packet-processing frames. The Promise API showed promiseFromApplication for the same query, and SELECT 1 succeeded.
What CoroPerf showed
The error traveled through Query.execute to Packet.asError. The callback API retained the socket’s allocation site but did not save the individual query call site.
Scope and limits
The first query opened the socket. Its creator cannot identify arbitrary later queries on a reused connection.
