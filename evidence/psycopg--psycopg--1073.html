Issue findings

Local observation
On 3.2.7, two fetchone calls on the reporter’s NULL/0 input both returned None, iteration yielded nothing, and streaming yielded only 0.
What CoroPerf showed
A traced async task had received three rows when its row maker mapped −1 to None and iteration stopped at position 1. A callback control read ID 1 three times before the fix and IDs 1, 2, 3 afterward.
Scope and limits
The report did not pin versions. The concurrent tasks and ID callback were local controls. A three-row streaming chunk was checked with bundled libpq 17.
