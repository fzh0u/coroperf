Issue findings

Local observation
With then on the main queue, the physical stack showed only the closure symbol, while inline execution retained registerFromApplication.
What CoroPerf showed
The same block was observed at dispatch_async and at callback execution, linking it to a submission stack containing PromiseKit.then and the registration function.
Scope and limits
The historical implementation was inspected, but the available run used Linux Swift and PromiseKit 6.18.1. The original iOS project and build settings were unavailable.
