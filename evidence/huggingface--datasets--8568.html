Issue findings

Local observation
In the posted program both ranks returned the same 15 rows after skip(1). In an independent run with 2,000 flight records, each rank read 1,999 flights and every row overlapped. On the fix each rank read 999 flights and the two sets were disjoint.
What CoroPerf showed
The stack from the original example reaches shard_data_sources in the skip wrapper. Asked to split four sources across two ranks, the affected method returned its own object with all four sources. The fix passed two sources to each rank. In an async feature calculation, the task created by iter_outputs on rank 1 processed row 1, which also appeared on rank 0. Its fixed counterpart began at row 501.
Scope and limits
The original script uses two logical ranks. A separate two-process run independently checked their full outputs against the source files. The coroutine creation and sample come from the supplementary async feature calculation.
