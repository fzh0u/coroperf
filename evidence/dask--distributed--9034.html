Issue findings

Local observation
The inner worker_client raised KeyError before submitting file work. Disabling its secede call, removing the outer context, or using the fix produced all four file sums.
What CoroPerf showed
The inner call tried to secede a thread that had already left the pool, while the fixed worker_client caught the internal KeyError and the task succeeded.
Scope and limits
The replay used a real local scheduler, nanny and worker with numeric files. The reporter’s ETL job was unavailable.
