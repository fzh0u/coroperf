Issue findings

Local observation
After cross-thread resumption, all six -O0 runs read the current thread and all six runs at each of -O1, -O2, and -O3 printed the original thread ID. All 24 same-thread controls were correct.
What CoroPerf showed
Early CSE reused the first pthread_self() value for the second call, and the final binary saved that value in the coroutine frame and reloaded it on resumption.
Scope and limits
The Linux test used an equivalent program with a joined worker and an independently held frame. Logs, GDB, IR, and the binary supplied distinct pieces of evidence.
