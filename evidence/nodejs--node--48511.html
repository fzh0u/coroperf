Issue findings

Local observation
The original Node program lost its higher-level async caller after an indirect call.
What CoroPerf showed
Promise creation records recovered main → indirectCall → foo, identifying the application call path that the default stack omitted.
Scope and limits
The V8 issue did not establish an internal cause, and the recorded chain does not identify an optimizer mechanism.
