Issue findings

Local observation
The unchanged GitHub example printed past its cancellation on CPython 3.10 and 3.11. On 3.12 the caller received CancelledError from the following sleep.
What CoroPerf showed
The affected wait_for frame received CancelledError while its inner Future was already done. It executed return fut.result() and the cancelled coroutine proceeded. The captured create-to-sample edge links that instance to main's create_task call.
Scope and limits
The comparison uses three installed Linux CPython builds. The graph time includes the rest of the reporter's run, including its deliberate sleep when cancellation is swallowed.
