Issue findings

Local observation
The upstream test published first and second with an unsubscribe limit of two. Version 2.16.0 and the fix parent recorded only first, while the fix commit and 2.17.0 recorded both.
What CoroPerf showed
The trace located cancellation in the subscription’s own Task and matched the queued messages to their callbacks. Changing the queue check from empty to empty() restored the second callback.
Scope and limits
The report identified a source error. The runnable test came from the closing PR and used one local NATS Core broker.
