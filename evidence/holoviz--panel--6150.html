Issue findings

Local observation
Clicking the original async and sync buttons in a real browser raised the same ValueError through different server callback paths.
What CoroPerf showed
The async wrapper led to async_on_click at line 7, while the synchronous callback reached sync_on_click at line 10. The affected Task was created as Tornado scheduled Panel’s async wrapper. The same Task produced the async_on_click exception stack.
Scope and limits
Server logs already identified both lines. No cross-process Task creation link or final upstream root cause was established.
