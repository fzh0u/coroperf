Issue findings

Local observation
In the two posted examples, filtering four records down to zero produced an empty pandas DataFrame with an integer column named a. Starting from an empty list returned an empty tuple. The two fixed builds produced the typed DataFrame in both cases.
What CoroPerf showed
The from_sequence call recorded zero input partitions on the affected builds. Bag.to_dataframe had the column metadata, but it scheduled zero conversion tasks. The finalizer called _concat with no partition results and returned the empty tuple. The fix created one empty partition. The worker converted it to a typed DataFrame, which the finalizer returned.
Scope and limits
The public example ran on the reported Python 3.6.5, Dask 0.19.3 and pandas 0.23.4. The directory experiment used local monthly files from the Seattle weather dataset. A calendar join checked 191 rainy days in 2012 and 1,461 dates in total against the source CSV under both synchronous and threaded scheduling. These traces cover ordinary calls and worker tasks.
