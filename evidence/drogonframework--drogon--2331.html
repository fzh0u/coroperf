Issue findings

Local observation
A PostgreSQL-backed HTTP request timed out when the profile path ran synchronous SQL on Drogon’s database event loop.
What CoroPerf showed
The blocked stack and the shared coroutine’s creation record pointed to profile_entry, and moving execution to a different loop allowed the request to finish.
Scope and limits
The Drogon 1.9.9 app recreated the reported mechanism. The original ORM project was unavailable.
