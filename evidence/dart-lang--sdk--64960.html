Issue findings

Local observation
In a real browser, the Wasm exception stack omitted the original async function at -O2 and retained it at -O0.
What CoroPerf showed
The loaded binary’s source map resolved the -O2 offset 0x4878 to the SDK’s async_patch, while -O0 and dart2js retained application source locations.
Scope and limits
The test used a Dart 3.14.0 sample and did not identify the optimization pass responsible.
