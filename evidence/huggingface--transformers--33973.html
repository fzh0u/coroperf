Issue findings

Local observation
On 40 held-out sentence pairs with human similarity ratings from 0 to 5, the regression head produced 38 scores above 1. Transformers 4.45.2 passed all outputs through a sigmoid. Its largest raw score, 4.4564, became 0.9885. With the same learned weights and inputs, 4.46.3 preserved 40 of 40 raw scores. The tables distinguish agreement with the model from agreement with the human ratings.
What CoroPerf showed
For the same input, the physical stack contains the final Linear.forward and the classification pipeline. The head value matches an independent dot product of its frozen weights and the recorded pooled vector. In TextClassificationPipeline.postprocess, 4.45.2 takes the single-output branch and executes scores = sigmoid(outputs). Passing function_to_apply="none" on that release returns the continuous score. The merge tests the explicit regression setting first. Unspecified and multi-label configurations still select sigmoid on both releases.
Scope and limits
Upstream classified this as a requested change to the default. Its own regression test configures a two-output DistilBERT fixture. That fixture takes softmax on the parent revision and returns the raw top score on the merge. The single-output experiment uses a locally fine-tuned BERT and a held-out sample of STS Benchmark image-caption pairs. Its scores measure this model on those inputs. The captured CPU inference functions are synchronous.
