Issue findings

Local observation
A single poll published two new model files, separate polls could publish the older file last, and replaying the two same-poll outputs made the first inference batch reject a singleton input of size two.
What CoroPerf showed
Both paths began with the same initial timestamp and each key’s singleton counter started at zero, allowing both models through the per-path state checks.
Scope and limits
Prism required separate jobs for live file polling and inference replay. The control used the proposed PR and a local multiplier model.
