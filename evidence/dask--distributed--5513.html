Issue findings

Local observation
On 2021.10.0, the async worker failed on a missing thread-local start_time, while the synchronous control processed the file and the async worker on 2023.6.0 returned 2016.
What CoroPerf showed
The upstream async-worker regression failed at the same line only on the older build; the newer code could catch the same exception during its check and still finish the job.
Scope and limits
The report specified “Latest” on macOS. The Linux comparison held Python 3.9.25 fixed and did not establish the first affected or fixed release.
