Issue findings

Local observation
In two uninstrumented runs, inputs numbered 0–9 printed 0 ten times, the scheduler ran one map task, and the ten outputs took 27.8 and 28.1 ms.
What CoroPerf showed
Ten distinct scatter tasks returned the same key i, so nine submissions reused the first map result, while hashing the whole dictionary produced ten keys and ten correct worker results.
Scope and limits
The local TCP cluster used two single-threaded workers. Creation evidence identifies client scatter tasks. Scheduler keys linked them to worker threads.
