Issue findings

Local observation
Opening the small file first failed twice when a 1,106,965-byte footer exceeded the 1,000,000-byte sample. Reversing the order read all 20,000 and 1,000 rows correctly.
What CoroPerf showed
File offsets and hashes showed that the 106,973 extra bytes belonged to the second file but were appended to the first buffer passed to PyArrow. The proposal appended them to the second.
Scope and limits
The original in-memory filesystem and both real files were checked independently. The stack was synchronous.
