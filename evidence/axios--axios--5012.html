Issue findings

Local observation
In the reporter’s script, Axios 1.0.0 serialized the loopback connection refusal without line 4 of main, while 1.21.1 retained that line.
What CoroPerf showed
The affected Promise’s creation stack contained line 4, but the error sample’s direct identity link led to the catch registered on line 8.
Scope and limits
The closing comment covered HTTP status errors. The first release to fix this connection-refusal case was not established.
