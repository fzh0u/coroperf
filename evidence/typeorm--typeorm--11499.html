Issue findings

Local observation
On TypeORM 0.3.24, a NULL for a required integer column returned SQL Server error 515 (EREQUEST) with a stack starting at SqlServerQueryRunner.js:204. A valid write was independently read back.
What CoroPerf showed
Promise identities connected each runner.query rejection and its await continuation to the originating importOrders or refreshCatalog call, even though both used the same SQL and produced the same error.
Scope and limits
The reporter’s Nest app and schema were unavailable. Two local callers exercised the reported versions, driver, query pattern and constraint. The intervals use V8’s Promise init and settlement notifications on the same Node clock. A second hook captured the rethrow stack during the settlement notification.
