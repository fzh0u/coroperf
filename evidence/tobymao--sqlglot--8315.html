Issue findings

Local observation
For (NULL, 1), old SQLGlot output returned (NULL, NULL) in SQLite, while the original SQL returned (1, 1) in PostgreSQL and DuckDB. The merge and 30.19.0 restored agreement.
What CoroPerf showed
Both generator functions received ignore_nulls=True but emitted bare MAX and MIN. The fix used the flag to build COALESCE expressions over rotated arguments.
Scope and limits
Checked constants, columns and deterministic integer expressions. MySQL was a generator-only control. The measured Python stack was synchronous.
