具体 issue 与可验证的增量

优先考虑 LMCache #1034 的 pin/unpin 生命周期，以及 Mooncake #4209 的失败到等待传播；#3490 是明确的性能线索，但原生原因已较清楚。

request → lookup/prefetch Task → KV object / transfer batch → completion Future → decode

跨这些边界需要记录真实 Task、KV 对象、batch 与 Future 的对应关系；CoroPerf 的通用 Task 创建关联不会自动给出全部 KV 语义。
