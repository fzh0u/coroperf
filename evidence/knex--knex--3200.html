Issue findings

Local observation
With asyncStackTrace set in Knex 0.16.5, a PostgreSQL conversion error omitted the caller. The same 22P02 error showed requestFromApplication with asyncStackTraces, and a valid ID returned data.
What CoroPerf showed
At saveAsyncStack, V8 showed the singular option was true but the plural option Knex actually reads was undefined.
Scope and limits
The breakpoint verified 0.16.5. Another user’s 0.16.3 environment was not tested.
