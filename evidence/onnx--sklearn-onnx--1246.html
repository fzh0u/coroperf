Issue findings

Local observation
The exported model classified all 500 test samples as class 1, disagreeing with scikit-learn on 271 labels with a maximum probability error of 0.460038, while an unwrapped tree worked.
What CoroPerf showed
Intermediate tensors showed logistic-transformed probabilities entering calibration. Passing the raw-score option to the child estimator restored correct probabilities with the same trees and coefficients.
Scope and limits
The replay covered binary gradient boosting, identity preprocessing, sigmoid calibration and the CPU execution provider.
