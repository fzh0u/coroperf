Issue findings

Local observation
Two workers held three keys and returned [3, 2, 7], yet the dashboard showed sum=3 and len=3. Adding one sum returned 17 and raised both counts to 4.
What CoroPerf showed
An empty fallback group name made both prefixes count all the same keys, and changing that fallback alone corrected the displayed counts.
Scope and limits
The original tasks ran on two local TCP workers. Chromium independently confirmed the rendered dashboard counts.
