Issue findings

Local observation
The example streamed the AI reply and then the original “hi” on 0.2.74 and the fix parent. Version 0.2.75 and the merge streamed only the reply, and all four builds preserved user-then-AI order in final state.
What CoroPerf showed
The old end callback published an input message whose ID was missing from seen. The fix registered it at node start, and all four upstream sync and async regressions switched from failing to passing.
Scope and limits
The report omitted its version. Its example was synchronous, and the verified Task came from the upstream asynchronous regression.
