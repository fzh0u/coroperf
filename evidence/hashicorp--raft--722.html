Issue findings

Local observation
The single-node test read 0 instead of 1 twice on both v1.8.0 and the PR parent, and a three-voter cluster also reported 0 after election and normal writes.
What CoroPerf showed
Disk, callback, snapshot, and cache evidence distinguished the membership index from ordinary log indexes, while storing membership and its index together made both proposed-fix runs pass.
Scope and limits
PR #723 was still a proposal. The Linux TCP/Bolt run supplements the macOS in-memory example. Only the local leader’s publication goroutine had creation evidence.
