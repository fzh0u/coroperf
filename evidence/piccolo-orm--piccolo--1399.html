Issue findings

Local observation
With [1, 2, 3] in the parent row, the first two queries succeeded, but prefetching the child with load_json raised TypeError in both the reporter’s example and the maintainer’s script.
What CoroPerf showed
The nested mapper passed the already-decoded list to the decoder again; restricting the second decode to strings and byte-like values preserved the original list.
Scope and limits
Database and driver versions were unspecified. Both upstream examples ran sequentially, and task creation was verified only in a separate two-query control.
