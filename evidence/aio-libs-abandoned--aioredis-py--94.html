Issue findings

Local observation
The stored list contained ab and cd throughout, but 0.2.4 returned bytes from EXEC with either inherited or explicit UTF-8, while a direct read returned strings.
What CoroPerf showed
Both versions received identical EXEC bytes. The closing commit decoded each queued command’s results with its own encoding before completing its Future.
Scope and limits
The report pinned only Python. The fix’s parent raised a separate TypeError, and release 0.2.5 still decoded a nested list explicitly requested as bytes.
