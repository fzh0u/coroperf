Issue findings

Local observation
The two reported labels were 0 and 1. Predicting 1 and 0 missed both. With zero_division=1, scikit-learn 1.3.0 and the fix parent returned F1 = 1.0. Version 1.2.2 and the fixed commit returned 0.0. All builds agreed on the other three reported examples, including the genuinely undefined all-negative case.
What CoroPerf showed
The live Python stack reached precision_recall_fscore_support through f1_score and fbeta_score. It recorded zero true positives, one predicted positive and one actual positive. The parent's intermediate denominator, precision plus recall, was zero, so it selected the configured fallback of one. The fixed implementation used the count denominator of two and returned zero.
Scope and limits
The report supplied four label arrays. The Iris predictions are a separate control using the same train/test split on six builds or runs. The nearest-centroid model scored 0.906629 macro-F1 on all 75 held-out flowers. The error-only comparison selects the 7 misclassified flowers from that holdout. The physical stack capture covers synchronous scoring of the first reported input.
