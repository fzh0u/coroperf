Issue findings

Local observation
For two records tied at the maximum key of 1, asyncstdlib selected second while Python’s max kept first. The fix also kept the earlier record in a 14-row database control.
What CoroPerf showed
The old _min_max combined invert with a less-than comparison using XOR, so equality executed best = item. The fixed version skipped that assignment.
Scope and limits
The posted example and upstream regression ran locally. The task origin belongs to the example’s main task, and the database cursor was a separate ordering check.
