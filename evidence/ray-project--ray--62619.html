Issue findings

Local observation
The base runs one cached-metrics Task per deployment handle. The proposal runs one shared Task on the router loop. With 128 idle handles and the default 100 ms interval, the median router-thread CPU per 850 ms window falls from 40.3–42.2 ms to 17.3 ms across two test orders, a 57–59% reduction. With no handles it stays below 0.13 ms. In a separate 16-handle check, the first reporting wave goes from 16 Task wake-ups to one, with the same 16 flushes and exact per-handle counter deltas.
What CoroPerf showed
The default version has two identical metrics execution stacks on the dedicated router thread. Each live asyncio Task matches the Task stored on its exact RouterMetricsManager. This joins observations 4 and 5 to creation records 1 and 3. The same asyncio Handle returned by call_soon_threadsafe runs during that creation, connecting it across threads to the corresponding DeploymentHandle.options initialization in record 0 or 2. The application frames distinguish chatbot and embedding callers even though both use the same deployment. Asyncio Task debug stacks stop at the common router-side callback. Both launch orders preserve the matches. In the proposal both managers flush in the same shared Task, and the exact registration Handle still recovers each caller.
Scope and limits
The comparison runs actual DeploymentHandle.options, router-thread initialization, cached metrics code, and Ray metric calls on Ray 2.59.0 with pinned router.py files. The controller transport is stubbed. The CPU measurement uses five idle windows per configuration and order after warm-up. The wake-up count and joined stacks use separate runs. This measures the local router thread with cached handles and excludes model requests or an external Prometheus scrape. The open proposal passes six upstream tests. In an additional lifecycle check, replacement concurrent with the last handle's shutdown leaves two reporters on the proposed revision. A local patch keeps one, preserves both counter deltas under both registration orders, and passes the same six tests. The issue and PR are open.
