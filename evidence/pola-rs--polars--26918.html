Issue findings

Local observation
For group a in the three-row example, Polars 1.39.0 returned 1 in memory and null in streaming mode. Both returned 3 for group b, and 1.40.1 returned null for a in both modes.
What CoroPerf showed
The Rust stack and row-replacement control localized the discrepancy to the grouped take after agg_arg_min: the old path took row indices, while the replacement preserved a null position.
Scope and limits
GDB recorded function entries. The internal validity bit was inferred from separate position queries, outputs and source. The original streaming query used only min_by.
