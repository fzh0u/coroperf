Issue findings

Local observation
Calling .done() produced an uncaught browser pageerror, while removing it produced an unhandled-rejection console diagnostic with the source.
What CoroPerf showed
A breakpoint showed the final Promise taking rejectUnchecked’s deferred rethrow branch, and the browser event still contained applicationOrigin.
Scope and limits
Chromium 159 reproduced the rethrow. The original page and Chrome build were unavailable, so the 2014 DevTools display could not be verified.
