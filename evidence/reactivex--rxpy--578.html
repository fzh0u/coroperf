Issue findings

Local observation
Rx 3.2.0 and the fix parent printed no rows for the upstream example, while the fix produced 2, 4, 12 and 16 in order.
What CoroPerf showed
The first source directly invoked the downstream completion callback with four values still queued and the second queue empty. The fix delayed completion until the finished source’s queue was exhausted.
Scope and limits
Ran the reported Rx release on Python 3.9.25 instead of 3.9.6. The example used a synchronous scheduler.
