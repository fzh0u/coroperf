Issue findings

Local observation
Two real HTTP 400 responses produced errors without a stack property in 0.27.0, while the same input produced stacks in 0.26.1 and 0.28.0.
What CoroPerf showed
V8 showed the property was already missing immediately after Error.call(this) in the AxiosError constructor, consistent with the upstream diagnosis.
Scope and limits
Checked on Node/V8 using constructor breakpoints and application observations.
