Issue findings

Local observation
The XHR error object said Network Error, while the browser’s separate network event recorded ERR_EMPTY_RESPONSE. HTTP 404 and 200 were also tested.
What CoroPerf showed
The exception stack ended at XMLHttpRequest.handleError, consistent with the browser withholding the underlying connection failure from XHR.
Scope and limits
The original Sentry session was unavailable, and the browser network event was an independent observation.
