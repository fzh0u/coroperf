Issue findings

Local observation
After nine successful pairs, 0.11.0 delivered two AssertionError objects in the tenth list, producing a blank space in one example and a TypeError during nested unpacking in the other. 0.12.0 used a tuple.
What CoroPerf showed
A failed child task held the same exception object as the batch, while a task that yielded a ValueError as data had no exception. The proposed type check confused those cases.
Scope and limits
PR #157 was unmerged. The Linux replay traced each __anext__ task separately. The gather completion callback had no coroutine identity.
