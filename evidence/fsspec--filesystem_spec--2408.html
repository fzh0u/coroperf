Issue findings

Local observation
For the static file abcdefghij, the reporter called cat_file(start=3, end=None). Both fsspec clients sent Range: bytes=3-. The server returned HTTP 200 with Content-Length 10 and the full document. On the reporter commit and the November 19 main-branch snapshot, both clients returned abcdefghij. Slicing the original file at offset 3 gives defghij. On a server that honored the request with HTTP 206 and Content-Range bytes 3-9/10, both clients returned those seven bytes. The first table shows the outputs shared by the aiohttp and Requests implementations in separate calls.
What CoroPerf showed
The full 200 response supplied no Content-Range. In range_response_window the start was 3 and the open-ended window had no length to check. With end=100 the calculated window was 97, also large enough to pass through the ten-byte body. The landed #2247 change caught the shorter [3:8] case. In the reporter capture, segment 1 identifies the actual HTTPFileSystem._cat_file coroutine. The trace hook found it in sync’s local variable before its first await. Its CPython cr_origin points to the preceding allocation line, coro = func(*args, **kwargs). The event loop’s _runner awaited that object. The same retained frame appears beneath range_response_window in segment 10. Two retained runs on the reporter’s build measured 7.298 ms and 7.402 ms from observing the created coroutine on the caller thread to the response stack on the I/O thread. Both events used the same process monotonic clock. The helper, coroutine and public caller all returned the same bytes object. In the separate CSV workload the file held four rows totaling 26 units. The second read returned the whole document and duplicated A and B, yielding six rows totaling 34 units on both affected snapshots.
Scope and limits
The original program uses the upstream test server. The control matrix uses a regular file served over loopback. The 2026.9.0 wheel needed the test fixture from its tag to run the posted script. The CSV uses one client reading two disjoint byte windows sequentially. Four observed runs matched 24 distinct request coroutines to their allocation in fsspec’s aiohttp-backed client at asyn.py:85 on the reporter commit and asyn.py:91 on November 19. Requests was measured separately. At the archived tracker snapshot, #2408 and PR #2446 were open. The proposal’s source head raised ValueError for the unconfirmed tail and returned defghij on 206. Its original script exited on the first client. Separate control calls exercised both clients.
