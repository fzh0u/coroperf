Issue findings

Local observation
In SDK 1.50.1, manually closing the loop destroyed a still-pending BaseApiClient.aclose Task. Draining the loop first removed the warning.
What CoroPerf showed
The Task’s creation traced to the SDK destructor, and its identity matched the object named by the destruction warning.
Scope and limits
The replay exercised local client cleanup only. Garbage collection and shutdown order affect the warning.
