Issue findings

Local observation
Enabling enhanced exceptions in Cats Effect 2.2.0 removed the application origin of a failed require.
What CoroPerf showed
IORunLoop.dropRunLoopFrames received 20 frames starting with Predef.require and the application’s foo but returned an empty array, consistent with upstream’s finding that the filter included the entire scala package.
Scope and limits
The same program ran with enhancement on and off in 2.2.0 and 2.3.1. The probe captured the actual input and returned frames.
