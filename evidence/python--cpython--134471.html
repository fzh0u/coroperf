Issue findings

Local observation
The posted program caught TimeoutError and printed that it continued on CPython 3.11 and 3.12. The reporter's 1 ms timeout control propagated CancelledError.
What CoroPerf showed
The same Task received the application cancel and the timer cancel. At Timeout.__aexit__, the incoming exception was CancelledError. The cancellation count fell from two to one, and the frame still raised TimeoutError. The graph joins the running test instance back to its allocation in the reporter's module.
Scope and limits
The 1 ms comparison changes one timeout literal in the reporter's script. The upstream issue remained open in the archived tracker. Times cover prepared local reproductions.
