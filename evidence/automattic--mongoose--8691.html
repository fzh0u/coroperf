Issue findings

Local observation
Directly awaiting a query with an invalid ObjectId produced a cast error whose stack omitted the application call site.
What CoroPerf showed
The promise creation stack showed Query.then calling exec internally, while calling exec explicitly on the same input exposed the application stack.
Scope and limits
Casting happened before the driver could send a database query.
