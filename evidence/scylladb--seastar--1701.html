Issue findings

Local observation
The original server’s streaming handler terminated on the affected build, while a control using a different write overload delivered the expected three bytes.
What CoroPerf showed
The native debugger located the termination in the chunked sink’s packet overload, isolating the difference between the two output paths.
Scope and limits
The local server used initialized response bytes and a private loopback listener.
