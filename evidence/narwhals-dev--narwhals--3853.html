Issue findings

Local observation
For [5.0, 1.0], Narwhals 2.17.0 returned 1.0 with PyArrow while pandas and Polars returned 3.0. The fix and 2.25.0 returned 3.0 for the whole column.
What CoroPerf showed
The old path selected approximate_median and finalized a t-digest, whereas the fix used a linear quantile, while grouped medians still returned 1 and 10 where the exact values were 3 and 15.
Scope and limits
The replay matched the reported interpreter and backend versions on Linux x86-64. The original platform was macOS ARM.
