Issue findings

Local observation
Bun 1.3.1 printed only fn3 inside AsyncLocalStorage.run, while the same program retained more frames outside it.
What CoroPerf showed
Pausing on the second exception recovered fn2, fn1 and the callback inside the store, locating the visibility change at the context boundary alongside the 1.3.14 control.
Scope and limits
The debugger supplied the JavaScript parent stack. The context-wrapper explanation comes from upstream source.
