Issue findings

Local observation
The two inserts from the report summed to 133.46 on all four rqlite versions. Version 7.5.0 and the fix parent sent an empty type name. The fixed revision and 7.21.3 sent real. Independent reads on each of three voting nodes also returned 412 invoices totaling 2,328.60. All 18 replica backups contained the same invoice rows.
What CoroPerf showed
The Go runtime trace follows the connection goroutine created by net/http through the rqlite HTTP handler into the SQLite driver. The driver returned an empty declared type for SUM. In that same goroutine rqlite scanned a float64 value of 133.46. The parent returned the empty metadata. The fixed query code filled it from the scanned value. A separate native SQLite check on each backup returned a null declared type and real storage for the aggregate.
Scope and limits
The original curl example used port zero. The local command used the port actually assigned to the server. The three-voter runs added a public Chinook invoice catalog and explicit replica-local reads. An expression with no rows or a null aggregate could still return an empty type after the fix.
