Issue findings

Local observation
Both documents in the original project returned 200, yet a real browser reported “Connection closed”. Correcting one HTML delimiter removed the error.
What CoroPerf showed
The production renderer linked four unexpected HTML values to the h component and request, and response-body and browser parsing checks corroborated the input change.
Scope and limits
This was an application-input issue. Browser and server observations were matched by document, and the lockfile differed from the reported React version.
