Issue findings

Local observation
The messages stream omitted the tool reply although synchronous history, final state, and the next model request retained its result and tool_call_id.
What CoroPerf showed
The tool ran and updated state, but the node-end extractor handled ordinary message dictionaries and missed the extra list around a Command, and the PR regression test passed on both fixed builds.
Scope and limits
The report did not pin a version. The 0.3.31 replay used the real ChatOpenAI client with deterministic in-process HTTP responses. Task attribution covers the supplemental astream callback.
