Issue findings

Local observation
With psycopg 3.2.3 and PostgreSQL 14.13, the reporter’s synchronous listener received 1 and 3 but missed 2, even though all three sends committed.
What CoroPerf showed
The query consumed the notification before ReadyForQuery and _notify_handler returned with no application callback. The fix queued the decoded object for the generator, which returned that same object.
Scope and limits
The replay used Linux, a Unix socket and CPython 3.12 instead of the reporter’s macOS environment. The creation graph used the pure-Python driver.
