Issue findings

Local observation
In the five-row example, Narwhals 2.11.0 returned [4, 4, 4, 6, 6] on pandas and PyArrow. Polars returned [0, 0, 0, 4, 4]. On the 344 Palmer penguin records, the two affected backends included every measured bird in each island’s total. For Dream Island they returned 460,400 g. The one bird there without a recorded sex weighed 2,975 g.
What CoroPerf showed
The stack reaches the grouping operation inside the window expression. On the affected build the numeric column still contains [2, 1, 1, 2, 4]. On the fix, the same boundary receives four nulls followed by 4. The conditional expression has removed the other four values before summation. Evaluating the condition in a separate column first also restores all three island totals on the old release.
Scope and limits
The original report does not specify dependency versions. The replay held pandas 2.3.3, PyArrow 22.0.0 and Polars 1.35.2 constant. SQLite window queries and an independent Python sum checked each returned row. The captured stacks are synchronous.
