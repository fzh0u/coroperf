Issue findings

Local observation
The original example printed only the warning message to stderr by default and included call frames with --trace-warnings.
What CoroPerf showed
The warning event already held an Error stack containing checkForgottenReturns, locating the difference in how Node displayed the warning.
Scope and limits
The reported package version ran on Linux rather than Windows. Native Node 6 warning observations did not establish promise ancestry.
