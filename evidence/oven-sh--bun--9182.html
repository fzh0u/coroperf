Issue findings

Local observation
Bun 1.0.29 reported #run and then for the posted ShellError but omitted the application line that created the command. 1.1.2 restored line 5.
What CoroPerf showed
Constructor probes distinguished the ShellPromise created at submission from the ShellError created at consumption. 1.1.2 allocated the error when the command was created.
Scope and limits
The main graph uses an additional constructor probe. The uninstrumented script invoked only a nonexistent local program.
