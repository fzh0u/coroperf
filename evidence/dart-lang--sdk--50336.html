Issue findings

Local observation
In the browser, the DDC-compiled program’s error stack omitted test1 and main even though each awaited the next call.
What CoroPerf showed
At the same Chromium exception pause, the debugger’s async parent stack recovered both callers, and ordinary page output and the Dart VM showed different caller coverage.
Scope and limits
The run used cached DDC 2.18.2 output and explicitly enabled browser debugging.
