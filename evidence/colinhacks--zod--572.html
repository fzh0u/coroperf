Issue findings

Local observation
Both 3.5.0 and 3.5.1 reproduced the full invalid_arguments result and all six reported file positions without the caller, while each release passed its 12 function tests.
What CoroPerf showed
A debugger showed the caller in the async parent stack. The proposed fork also restored the test line in the captured error for the same validation test.
Scope and limits
The report omitted the caller and lockfile. Both releases match, and the fork was tested only as a comparison.
