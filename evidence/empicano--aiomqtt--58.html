Issue findings

Local observation
In 0.9.0, a broker rejecting a retained will returned reason code 154, but the caller timed out after one second. Both retain-compatible controls connected and received a QoS 1 message.
What CoroPerf showed
ReasonCodes compared correctly with zero. The failure occurred when constructing the exception, and PR #59 let the original exception reach the caller by bypassing an integer-key lookup.
Scope and limits
The broker settings, reason code and one-second limit were local choices. The callback ran in an event-loop Handle.
