Issue findings

Local observation
The reporter’s two requests supply (1, 10) and (2, 20). The affected nightly returns (1, 10) and (20, 2). In a separate Iris classifier, mixed keyword order reverses 30 of 60 feature pairs and changes 16 predictions. The proposed batching change restores all 60 feature pairs and the correctly bound model’s 56 correct predictions.
What CoroPerf showed
The merge records carry the active Task, coroutine and coroutine frame. The same three identities link the echo merge (record 1) and the classifier merge (record 13) to their own creation records 0 and 12 in _process_sub_batches. The physical merge stacks share the same frames. The joined records identify the particular scheduled batch and preserve its arguments before and after the swap. In the selected classifier batch, the second row enters as sepal=46 and petal=15 and leaves as sepal=15 and petal=46.
Scope and limits
The reporter's Serve program and the classifier ran on a local CPU cluster using the same nightly commit as the original report. Two runs verify 95 creation-to-merge matches per variant. In a follow-up real deployment the open proposal rejects four valid calls with different argument layouts. The local draft groups those calls by model and layout, returns all four values, and preserves grouping for identical layouts and multiplexed models. Grouping may make sub-batches smaller.
