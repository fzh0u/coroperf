Issue findings

Local observation
A real SQLite-backed QuerySet returned green, blue and red in rank order through the async entry point. The synchronous call in 3.3.0a11 and the fix parent raised AttributeError when it read .result on a coroutine. Both the fixed commit and 3.3.0a12 returned the three rows.
What CoroPerf showed
The old synchronous list-completion code chose the async iterator on an object that supports both protocols. The creation stack, failed attribute access and subsequent warning referred to the same never-started coroutine. The fix chose synchronous iteration for the default sync entry point.
Scope and limits
The report described the QuerySet behavior without a complete application. The case reproduces it using Django 5.1.7 on SQLite. The coroutine never started and counts only in the extended origin total.
