Issue findings

Local observation
The historical CUDA worker and HTTP client produced 150 and 384 tokens. In three ordinary long-stream runs, the last 192 items arrived over 658.1–675.7 ms, with no observed AsyncStream backlog.
What CoroPerf showed
Pausing client reads for 0.7 s compressed parsing of the remaining items into 3.9 ms. Pausing only display compressed refreshes into 2.6 ms while parsing still spanned 678.2 ms, distinguishing two possible locations for a visible burst.
Scope and limits
Serial loopback requests with OPT-125M on one sometimes-shared A100. The original prompts, model, client and load were unknown, so the production cause remains open.
