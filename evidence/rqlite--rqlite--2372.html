Issue findings

Local observation
On 9.1.3, UPDATE RETURNING produced positional arrays despite the associative flag, including when a follower forwarded the write.
What CoroPerf showed
The request flag was true but the encoder flag was false in the same HTTP goroutine; copying the flag during execute response initialization restored the expected output.
Scope and limits
The report used macOS and the local comparison used three Linux nodes. Uninstrumented response bytes confirmed the formatting difference.
