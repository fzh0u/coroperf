Issue findings

Local observation
With the V8 stack limit set to two, Axios captured requestFromNamedCaller but omitted it from the reported error. Version 1.21.1 preserved it in the same script.
What CoroPerf showed
A debugger showed that short-stack deduplication treated an empty suffix as a duplicate and discarded the captured caller.
Scope and limits
Used the report’s custom adapter. The debugger supplied the key observation, and the graph contains no Promise parent edge for that breakpoint.
