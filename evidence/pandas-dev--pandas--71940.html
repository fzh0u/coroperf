Issue findings

Local observation
Grouping the reporter’s three floats into two groups raised “Mask must be 1D array” with Arrow, while pandas nullable floats and NumPy floats produced the correct four OHLC columns.
What CoroPerf showed
Aggregation had already produced the correct values and a two-dimensional mask when __arrow_array__ passed them to a one-dimensional conversion. The proposal preserved the result for table construction.
Scope and limits
The replay used Linux x86-64 instead of macOS ARM. Closed PR #71975 was built locally and was not verified as a released fix.
