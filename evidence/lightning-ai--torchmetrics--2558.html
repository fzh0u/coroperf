Issue findings

Local observation
On 56 labeled images, the released MeanIoU metric returned 18.811829 for a pixel-count mean of 0.335926. On two Gloo ranks the fix parent returned 9.405914 on each rank. The fixed code returned 0.335926. With the reference masks as perfect predictions, the single-process release returned 56, the two-rank parent returned 28 and the fix returned 1.
What CoroPerf showed
The parent added each image batch's mean IoU to its local score. At compute time it averaged the two rank sums and returned that value directly. The fixed metric sums both scores and batch counts across ranks, then divides. A forward call per image and one repacked update per rank both agreed with the independent oracle. The physical stack samples expose the local and synchronized states inside Lightning's validation hooks.
Scope and limits
The issue describes epoch-end validation but supplies no dataset or weights. The local image workload uses public Penn-Fudan photos and pedestrian annotations with a fixed brightness predictor. The 56 images are divided evenly across the two ranks. The separate issue-comment replay uses its four index-mask tests, including the target retained on the last step. The observed compute frames belong to synchronous CPU workers.
