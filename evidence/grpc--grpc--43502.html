Issue findings

Local observation
All 18 unary calls across six releases lost the message “my reason”, while sleep and a streaming RPC preserved it in the same process. An AnyIO unary timeout surfaced as CancelledError.
What CoroPerf showed
The inner _invoke Task received the message, cancelled itself again without it and finished cancelled, leaving the awaiter with a new empty exception. Rethrowing the original preserved the message.
Scope and limits
Task and exception identities were traced on Linux with CPython 3.11.13. The original cancellation had no pre-existing nonempty context.
