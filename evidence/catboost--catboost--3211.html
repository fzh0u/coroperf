Issue findings

Local observation
On the posted classifier, the same labels scored 1.0 as a vector and 0.5 as a column in CatBoost 1.2.10, the reported source revision and the fix parent. Inverting every label still gave 0.5 for the column. The fix returned 1.0 for the correct labels and 0.0 for the inverted labels.
What CoroPerf showed
The captured comparison paired each one-dimensional prediction with every row of the label column. The fix flattened the single-column labels before comparing. For a reordered five-row sample, the old score counted 13 of 25 pairs and the fixed score counted the three correct rows out of five.
Scope and limits
The experiment covers single-target CPU classification on Linux x86-64. The reporter used macOS arm64. The source comparisons shared the same release native extension, and the traced scoring calls ran synchronously.
