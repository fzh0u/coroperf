Issue findings

Local observation
The original Health/Check workload stalled when the observability plugin was enabled.
What CoroPerf showed
A native wait graph showed a circular dependency between the event loop and a mutex owner involving the GIL, and plugin controls distinguished a separate shutdown stall.
Scope and limits
Some Cython symbols were stripped. An independent native debugger supplied the lock relationships.
