Issue findings

Local observation
The synchronous SQLite history list exceeded two seconds, while the async entry point worked and the fixed synchronous path immediately raised InvalidStateError.
What CoroPerf showed
The Future returned by run_coroutine_threadsafe was the same object on which result() blocked, showing that the calling thread was waiting on its own loop.
Scope and limits
Only in-memory history enumeration was checked, using the reported packages and a newer Python patch release.
