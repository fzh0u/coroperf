Issue findings

Local observation
On Node 7.7.3 the reporter’s async error stack contained only functionOne, while the corresponding generator stack also showed functionTwo.
What CoroPerf showed
At the same throw site, both V8 debugger runs with async tracking recovered functionTwo at line 9, and both runs without tracking omitted it.
Scope and limits
Linux x64 replaced the reporter’s Windows 7 x64 system. The async parent frames came from V8 and did not identify the originating Promise object.
