Issue findings

Local observation
The 2017 example lost the call site for xxx() after delay(100). A separate 2020 Android test omitted a, which tail-called b.
What CoroPerf showed
Adding an unreached yield() after b(x) restored a at line 18 in the Android debug stack, supporting the maintainer’s tail-call explanation for the 2020 case. Neither release build showed a recovery boundary.
Scope and limits
Two public examples with incomplete device and build details. The earlier issue closure confirmed only the named throwing function in the 2017 example.
