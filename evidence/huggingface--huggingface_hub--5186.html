Issue findings

Local observation
During 1.5 seconds of mock polling the timer ticked zero times on the old SDK and 29 times after the fix. With a real local TCP queue the counts were zero and 31.
What CoroPerf showed
The request task made three status queries and one result query inside nested get_response calls before downloading the video, while the fixed task yielded at to_thread.
Scope and limits
All variants returned the same 1,099-byte, eight-frame video. The test covered local client polling without contacting a hosted model.
