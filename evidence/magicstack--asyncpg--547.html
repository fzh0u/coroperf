Issue findings

Local observation
The application never entered the connection context, yet the pool’s only slot remained occupied and close() did not return within 150 ms.
What CoroPerf showed
Cancellation discarded an already-completed acquire result before cleanup could run. 0.22.0 retained the result and released the same connection through the context manager.
Scope and limits
The test used one slot, CPython 3.7 and PostgreSQL 11. The wait was bounded, and uvloop was not tested.
