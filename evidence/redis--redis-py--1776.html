Issue findings

Local observation
Both commands returned True for abc, and moving three across lists also returned True even though Redis moved the requested element.
What CoroPerf showed
Both wire replies contained abc as a bulk string, and the client applied builtins.bool in the same response parser. Empty-string, empty-reply and SMOVE controls distinguished the conversion.
Scope and limits
Local Redis Community 6.2.3 and CPython 3.10.12 replaced Enterprise 6.2.3 and Python 3.8.10. The stack was synchronous.
