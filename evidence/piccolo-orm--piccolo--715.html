Issue findings

Local observation
On 0.101.0, creating A stored an empty string and creating B hit the optional_id uniqueness constraint, while 0.102.0 stored both rows.
What CoroPerf showed
The old mapper extracted values only from Equal conditions, leaving Varchar to supply an empty default, while the fix maps IsNull to None, and a default=None control also inserted successfully.
Scope and limits
The reporter supplied the app without version pins. Both calls shared one Uvicorn lifespan task. Separate tracing and database logs verified the bindings.
