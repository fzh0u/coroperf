Issue findings

Local observation
The JavaScript client received all three bytes of bar, but its parser reported an invalid packet type and delivered neither the event nor the acknowledgment to the application.
What CoroPerf showed
The sending task assigned the wrong type, and tracing matched the queued buffer to the received bytes; skipping binary-type conversion for MessagePack restored both callbacks.
Scope and limits
The report gave steps but no version or full app. A warm-up ensured the tested acknowledgment used ID 1, isolating a separate ID 0 behavior.
