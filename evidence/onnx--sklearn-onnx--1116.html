Issue findings

Local observation
The reporter trained a two-class linear discriminant model on 1,000 rows. For the first observation scikit-learn assigned the second class probability 0.52054489. The released converter produced an ONNX model that returned 0.5410205 on the same observation. Every row exceeded an absolute probability error of 0.00001. All 1,000 predicted labels agreed.
What CoroPerf showed
The converter wrote two opposite scores into the binary classifier. Applying softmax to that pair doubles the log odds. The proposed change applies the logistic transform for two classes. Its largest absolute error on the reported batch was below 0.00000006. Independent posteriors computed from class means, pooled within-class covariance and observed priors agreed with scikit-learn.
Scope and limits
PR 1285 was open and unmerged when checked. Both published versions tested reproduced the discrepancy. The original program uses seeded training data. The Wine controls train on alcohol and malic-acid measurements and score held-out rows. Stack captures observe Python conversion and runtime returns. The separate ONNX Runtime profiles identify CPU operators. No coroutine creation identity was observed.
