Issue findings

Local observation
A loopback request to /2 returned HTTP 500 on both builds, but only rc2 logged the ZeroDivisionError.
What CoroPerf showed
Samples captured the exception in root_fastopenapi and handle_request_async under _starlette_view, locating the change in the adapter’s error handling. Uvicorn’s handle_events created the ASGI request Task whose sampled stack includes root_fastopenapi.
Scope and limits
A single local route tested whether the server logged the exception.
