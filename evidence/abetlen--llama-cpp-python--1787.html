Issue findings

Local observation
Two localhost requests generated “Two plus two equals” and “Bananas”, four tokens and two tokens. Release 0.3.2 sent every score in the legacy text-completion arrays. OpenAI Python 1.54.3 exposed zero records in choices[0].logprobs.content, both for buffered chat and across the complete stream. Release 0.3.6 exposed all six records. All six selected token scores and all 18 top-three entries matched the same release’s text-completion control exactly. Turning off probabilities preserved both replies. Using all 151,936 native pre-softmax scores per position independently recovered the selected tokens and every reported top-three alternative within 4.33 × 10⁻⁷. A seventh native row per release identified the fruit reply’s stop token. Fresh processes reproduced the SHA256 of each complete vector.
What CoroPerf showed
On 0.3.2 the model worker yielded the original scores, and the chat formatter returned the same dictionary by identity. On 0.3.6 the sampled conversion helper built a new chat record for each token. CPython recorded the SSE publisher allocation through EventSourceResponse.__call__, AnyIO start_soon and call_for_coroutine before its first await. The same coroutine frame was the physical caller when the first scored chunk was sent. The buffered route also matched its creation and return frames. The decoding and mapping samples ran synchronously on a separate worker thread. A second fresh process per arm reproduced all scores.
Scope and limits
The reporter specified the endpoint and expected structure but supplied no checkpoint, prompt or exact version. The pilot fixture uses the public Qwen2-0.5B-Instruct Q4_0 model and a four-token cap. The fix first shipped in 0.3.3. A separate route error in 0.3.3 and a streaming cleanup error in 0.3.5 led us to use 0.3.6 for the complete HTTP comparison. The exact parent and fix ran through their own public Llama API and produced identical underlying scores. The released native libraries differ, so numerical controls are evaluated within each release.
