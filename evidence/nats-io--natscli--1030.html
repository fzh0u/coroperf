Issue findings

Local observation
The first and last timestamps of a three-replica stream displayed local clock times in UTC−6 and UTC+05:30, yet both lines retained the UTC label.
What CoroPerf showed
Sequence reads, node monitoring and CLI JSON agreed on the timestamps, while the formatting stack and a two-line patch isolated the literal label in the client.
Scope and limits
Two messages covered the first and last sequence. The CLI debug stack was checked against uninstrumented output and carried no goroutine creation record.
