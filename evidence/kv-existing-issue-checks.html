LMCache #2080：计算预算与外部 KV 预留分离

真实 scheduler、KV cache manager 与 block pool 的文件哈希均匹配安装包 RECORD。额外观察记录了提交 Task 与 Request 对象 ID、提交栈；未接入通用 CoroPerf 采集，未验证实际 KV 对象归属或工具诊断增量，因此不加入精选目录。该次结果已冻结，不运行基线、修复或完整 PD 变体。运行范围与完整性记录。
