Issue findings

Local observation
On the same five-row table, repeating an equality condition inside OR dropped (5,I) from the three matches on the reported commit, 1.3.2, and 1.4.0.
What CoroPerf showed
Native stacks and separately observed row values showed the search choosing one candidate by time and stopping when the residual predicate rejected it, despite a valid alternative.
Scope and limits
The Linux x86-64 run used synchronous native stacks. Separate probes supplied row values. The report used macOS ARM64.
