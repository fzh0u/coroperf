Issue findings

Local observation
After resuming the posted graph, the last stream event reported no parent despite the checkpoint having a parent ID. With earlier history, the event could report the grandparent.
What CoroPerf showed
Skipping an intermediate save left prev_checkpoint_config stale when map_debug_checkpoint emitted it, although aput later wrote the correct parent to SQLite.
Scope and limits
The original used synchronous InMemorySaver. Task evidence came from the AsyncSqliteSaver control, and the tested change from #9585 was never merged.
