Issue findings

Local observation
The async main-queue callback’s physical stack omitted submitFromApplication, which remained visible in the synchronous control.
What CoroPerf showed
The same block address at dispatch_async submission and callback execution identified the submitter.
Scope and limits
The capture used Linux libdispatch. The original UIKit action, Apple build and matching dSYM were unavailable.
