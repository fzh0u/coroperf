Issue findings

Local observation
A same-value CAS returned HTTP 200, but reusing its reported index returned 409 in both trials on each affected release, while all three replicas retained the same value.
What CoroPerf showed
The Raft apply stack traced the wrong response index to the unchanged-value branch, while the isolated fix and 1.8.0 preserved the original index and advanced only keys that changed.
Scope and limits
The test used ordinary KV transactions on three healthy local voters. The identified FSM goroutine belonged to the replay.
