Issue findings

Local observation
The upstream generator regression encountered the same task again while traversing waiters, and the fixed test completed.
What CoroPerf showed
The affected getter returned its own task pointer. The fixed getter returned a different task. The affected reference and stripped runs timed out, while the affected queue-control run and both fixed runs completed.
Scope and limits
Only the waiter-chain cycle was checked. The separate early-yield initialization path was not tested.
