Issue findings

Local observation
After the original development app threw, its physical render stack omitted the parent App Router components.
What CoroPerf showed
CoroPerf recovered the React owner chain Home → AsyncComponent → ThrowingComponent in all six throws across three instrumented runs. The control with owner links disabled recovered zero complete chains across six throws. Source observations independently checked each ownership link.
Scope and limits
The comparison measures JSX ownership in the React development renderer. The original application and dependencies are pinned to Next.js 15.1.4 and React 19.0.0.
