Issue findings

Local observation
On Android API 34, the reporter’s Kotlin Activity reached the controlled Dart main, but manual pauses showed zero frames with either one or two Futures waiting.
What CoroPerf showed
Registration logs linked waitAlpha and waitBeta to main. Releasing A left B pending, and releasing B allowed the first frame to render.
Scope and limits
Only part of the Dart app was public. The reported intermittent startup failure lacked the main-entry log seen here, so its blocking point remains unknown.
