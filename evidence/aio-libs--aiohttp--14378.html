Issue findings

Local observation
The report cited about 23 ms at 256 concurrent requests, and the loopback replay confirmed later request headers and a later first response chunk with trust_env enabled.
What CoroPerf showed
Supplying local credentials eliminated one executor submission, leaving only the proxy lookup, while disabling trust_env eliminated both submissions before headers were sent.
Scope and limits
The replay used no vLLM server and did not time pool queuing, file reads, or event-loop resumption separately.
