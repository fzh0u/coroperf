Issue findings

Local observation
The old implementation returned 2 for the author’s four foreground-free samples and 1.34 for a valid mixed batch, whether updated together or separately.
What CoroPerf showed
The fix and release 1.6.2 returned 0 and 0.34 on the same inputs and passed all four upstream regression assertions. The fix’s parent retained the inflated scores.
Scope and limits
Zero for an empty foreground is the upstream convention. The replay used the default single-process DiceScore on Linux CPU. The reporter used macOS.
